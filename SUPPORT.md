# Support

## Get help

- **Questions and ideas:** use [GitHub Discussions](https://github.com/tushar-mahalya/kdev/discussions).
  Choose *Q&A* for how to do something or whether what you see is expected.
- **Bugs:** open a [bug report](https://github.com/tushar-mahalya/kdev/issues/new?template=bug_report.yml).
  Include the output of the same command with `-v`, the kdev version and your
  operating system.
- **Documentation problems:** open a [documentation issue](https://github.com/tushar-mahalya/kdev/issues/new?template=documentation.yml).
- **Security issues:** do not use a public issue. Follow [SECURITY.md](SECURITY.md).

## Before you ask

1. Read the [README](README.md) and the [troubleshooting page](https://kdev-cli.pages.dev/docs/troubleshooting/).
2. Run `kdev doctor`. It checks every dependency, each account's token, the
   workspace and the tunnel's DNS.
3. Search existing issues and discussions.

## Expectations

kdev is maintained by one person in their own time. There is no guaranteed
response time. Only the latest release receives fixes.
